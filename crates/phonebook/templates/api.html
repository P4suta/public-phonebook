Public Phonebook API

公開されている施設・窓口の連絡先を、登録やAPIキーなしで取得できます。

OpenAPI（JSON）APIの入口（JSON）種類・地域・収録件数（JSON）

検索して試す

施設名の一部か、電話番号を入力してください。









リクエストの例


curl
curl --fail-with-body --get --data-urlencode 'q=横浜市役所' /api/contacts


TypeScript
const response = await fetch('/api/contacts?q=横浜市役所');
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const result: unknown = await response.json();
console.log(result);


URLのパラメータはURLSearchParamsやHTTPクライアントの機能でエンコードしてください。






取得できるもの


GET内容


/api各APIと一括取得のURL


/api/contacts検索・都道府県・市区町村・種類の絞り込み


/api/contacts/{id}1件の連絡先と出典・保存のURL


/api/sources出典の一覧


/api/sources/{id}元資料のURL・SHA-256・取込結果


/api/catalog種類のID・地域コード・収録件数


/api/export該当する全件をJSON・CSV・vCardで取得








検索と全件取得


qは施設名の部分一致、電話番号は表記を揃えた完全一致です。


prefectureは01〜47の2けた、municipalityは5けたの地域コード、categoryは種類のIDです。


検索は1ページ50件です。links.nextをたどり、nullになったら終了です。


返すURLは同じサイトを起点にした相対URLです。JavaScriptではnew URL(link, response.url)で解決できます。


全件が必要な場合はexports.jsonまたはexports.csvを取得してください。一括取得にページの指定は不要です。


各URLのsnapshotはデータの識別子です。409が返った場合は/apiから取り直すと、異なる時点のデータの混在を避けられます。






出典と利用条件


各レコードのsource_url、license、license_url、data_as_of、retrieved_atを引き継いでください。


データごとに利用条件が異なります。加工の表示とattributionも確認してください。


資料の時点・取得日は、現在も番号が使えることの確認日ではありません。


CSVの文字列には数式対策の接頭辞があります。元の文字列が必要な場合はJSONを取得してください。






エラー


失敗時はapplication/problem+jsonでcodeとrequest_idを返します。


リクエストURLの上限はエンコード後8192バイト、qはUTF-8で512バイトです。




400・invalid_query
invalid_parametersに示す入力を直してください。未知のパラメータ、重複した指定、範囲外のページもエラーです。


404・not_found
この時点のデータに連絡先または出典がありません。


405・method_not_allowed
GET・HEADで取得できます。ブラウザ向けのOPTIONSにも対応します。


409・snapshot_changed
データが更新されています。APIの入口から取得をやり直してください。


503・unavailable
Retry-Afterの秒数を待ってから再試行してください。




ブラウザからの取得にも対応します。Cookieや認証情報の送信は不要です。
